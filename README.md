# Sudoku

Jogo de Sudoku desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades

- Grade tradicional 9×9 com blocos 3×3.
- Níveis fácil, médio e difícil.
- Validação das respostas durante o jogo.
- Destaque da linha, coluna, bloco e números relacionados.
- Cronômetro, contagem de erros e pontuação.
- Botão para iniciar um novo jogo.
- Dicas com desconto na pontuação.
- Opção para limpar as respostas.
- Opção para revelar a solução.
- Layout responsivo para computador e celular.

## Como jogar

Abra o arquivo [index.html](./index.html) em um navegador moderno. Não é necessário instalar dependências ou executar um servidor.

Preencha as casas vazias com números de 1 a 9. Um número não pode se repetir na mesma linha, coluna ou bloco 3×3.
